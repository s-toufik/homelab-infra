# PostgreSQL

PostgreSQL 18, run by the [CloudNativePG](https://cloudnative-pg.io) operator from kube-charts' `pg-cluster` chart, tuned lightly for a 4 GiB pod on a 32 GiB host (`shared_buffers=1GB`, `effective_cache_size=3GB`). Settings, roles and databases are in [`values.yaml.gotmpl`](values.yaml.gotmpl).

| Database | Owner | Used by |
|---|---|---|
| `homelab` | `homelab` (password generated by the operator, Secret `postgres-app`) | Tasker's schema (`migrations/`), read and written by PostgREST as `postgrest` → `tasker_web` |
| `keycloak` | `keycloak` (Secret `pg-role-keycloak`) | Keycloak's accounts and sessions |

- From pods: `postgres-rw:5432` (the primary).
- Roles `postgrest` and `keycloak` are declared: the operator creates them, keeps their attributes and memberships, and applies a new password from their Secret within seconds (`make secret-rotate`).
- The `postgres` superuser's password is in Secret `postgres-superuser`; `make psql` opens a shell inside the pod without it.
- Metrics: the operator's exporter on port 9187 of the pod, scraped by Prometheus.
- A major upgrade (18 → 19) is a new image plus the operator's in-place major upgrade; read its notes first, after a backup.
