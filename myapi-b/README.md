# myapi-b

Placeholder FastAPI service that calls **myapi-a** over HTTP. Because both are instrumented, W3C `traceparent` headers propagate automatically and you get a single trace across the two services, plus a service-graph edge `myapi-b → myapi-a` in Grafana (generated by Tempo's metrics-generator).

| Endpoint | Behaviour |
|----------|-----------|
| `GET /health` | liveness |
| `GET /chain?fanout=3` | calls `myapi-a /work` N times in parallel (1–20) |

URL: http://<server>:8002/docs

## Generate some traffic

```bash
for i in $(seq 1 200); do curl -s "http://localhost:8002/chain?fanout=5" > /dev/null; done
```

Then in Grafana: **Explore → Tempo → Service Graph**, or search traces with TraceQL: `{ resource.service.name = "myapi-b" && status = error }`.
